# Encore

An offline music player for Android that plays local files and shows karaoke-style synced lyrics.

## Planned for v1
- Scan and list local songs
- Playback with background controls
- Lyrics screen with the current line highlighted (from `.lrc` files or embedded tags)

## Build
Pushing to `main` runs the **Build APK** workflow. Download the debug APK from the run's Artifacts.
